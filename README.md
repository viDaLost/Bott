# Bott — бот для скачивания видео и музыки на Telegram Serverless

Бот работает прямо в облаке Telegram ([Telegram Serverless](https://core.telegram.org/bots/serverless)):
не нужен ни сервер, ни Docker, ни хостинг. Код — JavaScript-модули в папке `tgcloud/`,
деплой одной командой `npm run deploy`.

## Возможности

- 🎬 **Видео по ссылке — всё внутри Serverless, без своих серверов:**
  - **TikTok** — видео без водяного знака, фото-карусели альбомом, звук (через TikWM);
  - **YouTube** — аудио M4A в лучшем качестве и видео со звуком (обычно 360p: склеить отдельные дорожки HD без ffmpeg нельзя);
  - **Instagram** — Reels, видео, фото и карусели открытых постов. ⚠️ Instagram блокирует запросы с серверов Telegram (проверено: GraphQL отвечает 403), поэтому сейчас посты чаще всего не скачиваются — бот пробует три способа и честно сообщает, если ни один не сработал;
  - **X (Twitter)** — видео и фото (через FxTwitter).
- 📉 **Подбор под лимит.** Бот выбирает лучший формат, который влезает в лимит Telegram.
- 🎵 **Поиск музыки по названию.** Просто напишите название или `/music название`, выберите трек — бот пришлёт его аудиофайлом. Результаты листаются страницами («◀ Назад» / «Ещё ▶»), до 200 треков.
- 📝 **Поиск по строчке из песни:** `/lyrics фрагмент` (Genius).
- 🎧 **Распознавание музыки** из голосового, кружка или аудио (AudD).
- ⚡ **Мгновенные повторы.** Бот запоминает `file_id` отправленных файлов. Повторный запрос (даже по другой ссылке на то же видео: `youtu.be`, `watch?v=`, Shorts) отправляется без скачивания.
- 📊 **Прогресс загрузки** в процентах и кнопка «Отмена». Отменить может только тот, кто запустил загрузку.
- 🔒 **Ограничение доступа** по Telegram ID, команды владельца прямо в чате.
- 👥 **В группах** бот реагирует только на ссылки и команды и не отвечает на обычную переписку.

## Что изменилось по сравнению со старой версией (Python)

Telegram Serverless запускает JavaScript в изолятах V8. Там нет файловой системы, npm-пакетов и внешних программ, поэтому yt-dlp, ffmpeg и shazamio там не работают. Бот переписан так:

| Было | Стало |
|---|---|
| yt-dlp + ffmpeg на своём сервере | собственные загрузчики на JS: API плеера YouTube, GraphQL Instagram, TikWM для TikTok, FxTwitter для X |
| поиск через yt-dlp | внутренний поисковый API YouTube, запасной путь — YouTube Data API |
| Shazam (shazamio) | [AudD](https://audd.io) |
| SQLite / Cloudflare D1 | встроенная база Serverless (SQLite) |
| переменные окружения | несекретное — в `tgcloud/lib/config.js`, токены — командой `/set` в чате |
| очередь загрузок в памяти | состояние загрузок в базе: отмена и защита от повторного запуска работают между вызовами |
| Timeweb, Docker, health-check | ничего этого не нужно |

Старая версия лежит в папке `legacy/`. На Serverless она не деплоится. Если понадобится, её по-прежнему можно запустить в Docker.

Ограничения платформы:
- файл до **49 МБ** (лимит Bot API, свой Local Bot API Server здесь не подключить);
- без ffmpeg нельзя склеивать и перекодировать: видео с YouTube — в «готовом» качестве со звуком (обычно 360p), музыка — в M4A, а не MP3, обложки не вшиваются;
- звук отдельно можно получить из TikTok и YouTube; из Instagram и X — только видео;
- YouTube и Instagram иногда ограничивают запросы с серверов: тогда бот честно напишет, что сайт не отдал файл.

## Установка с телефона (через GitHub Actions)

Компьютер не нужен: деплой выполняет GitHub.

1. **Включите Serverless у бота:** @BotFather → ваш бот → **Settings → Serverless**.
2. **Скопируйте токен:** там же **CLI Access → Access token** (вид `app123456:секрет`).
3. **Добавьте токен в GitHub.** Откройте github.com в браузере телефона: репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Имя `TGCLOUD_TOKEN`, значение — токен. В приложении GitHub этого раздела нет, нужен браузер; при необходимости включите «Версия для ПК».
4. **Запустите деплой:** вкладка **Actions → Deploy → Run workflow**. Деплой также запускается сам при каждом пуше в ветку `claude/telegram-serverless`. Workflow прогоняет тесты, выкладывает код и создаёт таблицы в базе.
5. Напишите боту `/id`, впишите полученный ID в `tgcloud/lib/config.js` → `OWNER_IDS` (можно прямо на github.com: карандаш «Edit» → Commit). После коммита бот задеплоится заново. Затем отправьте боту `/setup` и `/settings`.

## Установка с компьютера

Нужен Node.js 22.5 или новее.

1. **Включите Serverless у бота:** @BotFather → ваш бот → **Settings → Serverless**. Активация может занять некоторое время.
2. **Впишите свой ID** в `tgcloud/lib/config.js` → `OWNER_IDS = [123456789]`. Свой ID можно узнать у [@userinfobot](https://t.me/userinfobot) или после деплоя командой `/id`.
3. **Подготовьте проект и привяжите бота:**
   ```bash
   npm install
   npx tgcloud init      # создаст служебную папку .tgcloud/, существующие файлы не трогает
   npx tgcloud login     # токен: @BotFather → бот → Serverless → CLI Access → Access token
   ```
   Токен имеет вид `app123456:секрет`. Не публикуйте его. Для CI вместо `login` задайте переменную `TGCLOUD_TOKEN`.
4. **Задеплойте и создайте таблицы:**
   ```bash
   npm run deploy        # = npx tgcloud push
   npm run migrate       # = npx tgcloud migrate — применить tgcloud/schema.js к базе
   ```
5. Напишите боту `/setup` (обновит меню команд) и `/settings`.

> ⚠️ Если старая версия бота ещё запущена на Timeweb, остановите её. Serverless ставит боту webhook, и бот на polling перестанет получать сообщения или начнёт с ним конфликтовать.

После любых изменений кода: `npm test`, затем `npm run deploy`. После изменений `tgcloud/schema.js` нужно ещё `npm run migrate`.

## Настройки из чата (только владельцу)

| Команда | Что делает |
|---|---|
| `/settings` | показать, что настроено |
| `/set ключ значение` | задать настройку; сообщение с секретом бот сразу удаляет |
| `/unset ключ` | удалить настройку |
| `/allow ID` / `/deny ID` | открыть/закрыть доступ (можно ответом на сообщение пользователя) |
| `/users` | кому открыт доступ |
| `/stats` | загрузки за сутки, размер кэша |
| `/setup` | обновить меню команд бота |

Ключи для `/set`:

| Ключ | Зачем | Где взять |
|---|---|---|
| `cobalt_url`, `cobalt_key` | необязательно: свой сервер cobalt (см. ниже) | — |
| `genius_token` | `/lyrics` | [genius.com/api-clients](https://genius.com/api-clients) → Client Access Token |
| `audd_token` | распознавание музыки | [dashboard.audd.io](https://dashboard.audd.io) |
| `youtube_key` | запасной поиск, если основной не отвечает | Google Cloud → YouTube Data API v3 (≈100 поисков в сутки бесплатно) |

Доступ: если `ALLOWED_USERS` в `config.js` пуст и через `/allow` никто не добавлен, бот доступен всем. Владельцам он доступен всегда. Команда `/id` работает и без доступа: человек узнаёт свой ID и передаёт его владельцу.

### Необязательно: cobalt

Бот целиком работает на Serverless и без него. Если когда-нибудь понадобятся HD-видео с YouTube или другие сайты (VK, Reddit и т. п.), можно подключить свой сервер [cobalt](https://github.com/imputnet/cobalt) командами `/set cobalt_url …` и `/set cobalt_key …` — тогда бот будет пробовать его первым, а встроенные загрузчики останутся запасным путём.

### Проверка источников из облака

После каждого деплоя workflow запускает `scripts/probe-endpoint.js` прямо в облаке Telegram (без деплоя этого модуля) и печатает в логе, отвечают ли YouTube, TikTok, Instagram и X с адресов, откуда работает бот: шаг **«Проверка источников»** во вкладке Actions.

## Структура

```
tgcloud/
├─ schema.js              таблицы базы
├─ handlers/
│  ├─ message.js          входящие сообщения → lib/bot.js
│  └─ callback_query.js   нажатия кнопок → lib/bot.js
└─ lib/
   ├─ bot.js              команды, ссылки, поиск, распознавание, кнопки
   ├─ download.js         скачивание и отправка, кэш file_id, карусели
   ├─ transfer.js         потоковая загрузка в память с прогрессом и лимитом
   ├─ job.js              статус загрузки, прогресс, отмена
   ├─ search.js           поиск музыки со страницами
   ├─ storage.js          все запросы к базе
   ├─ settings.js         настройки из /set и проверка доступа
   ├─ config.js           владельцы, лимиты, качество
   ├─ links.js, targets.js, text.js, music.js
   └─ sources/            youtube.js, tikwm.js, instagram.js, twitter.js, cobalt.js
test/                     тесты на заглушках платформы (npm test)
scripts/probe-endpoint.js проверка источников из облака (запускается в CI)
.github/workflows/        деплой через GitHub Actions
docs/tgcloud-sdk.md       справочник SDK платформы
legacy/                   старая версия на Python (не деплоится)
```

## Важно

Скачивание контента может нарушать правила площадок и авторские права. Бот рассчитан на личное использование. При публичном доступе возможны жалобы и блокировки.
